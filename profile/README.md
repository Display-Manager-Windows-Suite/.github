## 📖 Introduction
Display Manager for Windows is a complete tool for managing everything about your displays. It adjusts brightness and contrast on supported monitors, arranges screens, applies color profiles, sets resolution and refresh rates, and divides each display into zones for tidy window snapping. Save profiles for different scenarios — a focused single-window layout, a wide multitasking grid, or a presentation setup — and switch in a click. As a brand-neutral display manager, it works across the monitors on your desk without relying on any one vendor's utility, keeping your whole display setup in order on a Windows PC.

## ✨ Highlights

### Manage displays
- **Brightness and contrast** — Adjust supported monitors via DDC/CI.
- **Arrangement and resolution** — Position screens and set resolution and refresh.
- **Color profiles** — Apply and switch ICC color profiles per display.

### Manage windows
- **Zones and layouts** — Snap windows into custom regions on each screen.
- **Profiles** — Save setups and switch them instantly.
- **Brand-neutral** — Works across monitor brands with standard controls.

## 🤔 Common Questions
**Is Display Manager free?**
Yes. It is a free display management tool for Windows, with no subscription required.

**What is DisplayLink Manager, and is this the same?**
DisplayLink Manager is a separate Synaptics app that runs DisplayLink USB docks and adapters. This Display Manager is different — it arranges and adjusts your monitors rather than driving a dock.

**Which versions of Windows are supported?**
Windows 10 and Windows 11 (64-bit). Installing the latest stable release is recommended.
